# poizon选品 — 方案与执行路线

## 目标
LV 韩国直邮 → 得物倒卖。自动抓 LV 韩国价/可售状态 + 得物市场价/销量，按差价、利润率、
销量、库存、竞争、资金占用综合打分，选出最值得做的品。

## 关联键
**LV 官方货号**（如 `M81234`）。两侧都带，是自动对比的基础。

## 两条数据链路

### LV 韩国（已探明）
- 走移动 App 接口 `pass-api.louisvuitton.com/api/catalog/product/{货号}?locale=ko_KR`，**不爬网页**（网页 Akamai 直连 403）。
- 关键字段：`sellableStatus.price.price`(价格)、`sellableStatus.sellable`(可售)、`isBackOrder`、`skus[]`(规格)。
- 反爬：curl_cffi 伪装 TLS 指纹 + 韩国住宅代理 + 控频。
- 待真机抓包确认：`ko_KR` 拼写、host 是否对韩国一致、是否需 client_id/secret 头。

### 得物（待核实）
- 官方开放平台 `open.poizon.com` 确认能：按品牌拉 LV 全量 SPU/SKU、按货号查、管自己店铺。
- **不确定**：是否开放"任意商品市场价/销量/想要"行情数据。**阶段 1 用商家账号登录核实。**
- 若不开放 → 用屏幕控制得物电脑版兜底（`src/dewu_source/screen_control.py`）。

## 需用户提供
1. open.poizon 账号密码（阶段 1）
2. 韩国住宅代理 host:port:user:pass（阶段 2）
3. 主营货号清单 CSV（阶段 3）
4. 成本参数：退税比例、直邮物流费、清关、鉴别包装、得物佣金率、转账手续费、汇率（阶段 3）

## 利润模型
```
采购成本 = LV价(KRW)×(1−退税率)×汇率 + 物流 + 清关 + 鉴别包装
得物到手 = 市场价 ×(1−佣金率−手续费率) − 固定费
净利润   = 得物到手 − 采购成本
利润率   = 净利润 / 采购成本
```

## 评分模型
分项归一化(0~1)后加权，负向指标取反。权重见 `config/settings.yaml`：
利润率 .30 / 绝对利润 .25 / 销量速度 .25 / 库存稳定 .10 / 竞争(负) .10 / 资金占用(负) .05 / 价格波动(负) .05。
硬过滤：净利润下限、利润率下限、LV 必须可买。

## 合规与风控注意
- LV 抓取控频、用住宅 IP、走 App 接口，降低封禁与法律风险。
- 得物优先官方 API；屏幕控制比逆向爬虫更不易触发风控。
- 退税合规按你实际离境退税渠道，参数化在 settings。
