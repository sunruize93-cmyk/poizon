# LV 半自动抓价（Safari 控制台法）

## 为什么需要它

`tools/lv_prices.mjs`（patchright 自动暖机首页 → 抓价）**自 2026-07 起被 Akamai 首页级封死**：
全新 profile、换 IP（机房代理 / Korea Telecom / LG U+ 住宅 / **KT 移动热点**）一律在
`kr.louisvuitton.com/homepage` 秒回 `Access denied`。已排除是代码/patchright 版本问题
（patchright 1.61.1 未变，7/8 还能抓），也不是单纯 IP 信誉（最干净的移动 IP 也被拒）——
是 Akamai 服务端把首页行为校验整体调严了。**别再靠换 profile/IP 硬试**（每试一次加深封禁）。

## 可靠替代：真人过 Akamai + 控制台 fetch

核心思路：LV 认的是「真人浏览器会话」。让用户在 **Safari** 里手动打开 LV（Akamai 放行、
拿到有效 cookie），再在**控制台里 fetch** 商品详情接口逐货号取价。价格接口只需
`client_id/client_secret` 头（LV 网页公钥，固定可复用）+ 会话 cookie，货号即可取价、无需 nvprodId。

### 三步流程

```bash
# 1) 生成 Safari 控制台代码（凭证从 .env 注入，输出到 gitignored 的 data/lv_snippet.js）
python tools/lv_snippet_gen.py 货号1 货号2 ...      # 指定货号
python tools/lv_snippet_gen.py --missing 5           # 或自动：缺价且中国销量≥5 的货号

# 2) 用户在 Safari 操作：
#    a. 打开 kr.louisvuitton.com（若 Access Denied 按 ⌘R 刷新一两次）
#    b. ⌥⌘C 开 JavaScript 控制台（需先在 设置→高级 勾选"显示开发菜单"）
#    c. 把 data/lv_snippet.js 整段贴进去回车 → 逐货号 fetch，跑完 copy() 到剪贴板
#       （每 40 个打印一次进度；~0.46s/货号）

# 3) 把控制台输出粘到一个文件，合并回价库
python tools/lv_merge_paste.py <粘贴内容文件>         # 兼容纯JSON 和 双重转义两种形态
python tools/run_select.py                            # 重跑三条线出榜
```

### 凭证

`LV_CLIENT_ID` / `LV_CLIENT_SECRET` 存在 `.env`（gitignored）。它们是 LV 网页公钥、固定可复用，
从真实 PDP 的 API 请求头里抓到。生成器把它们注入到 `data/lv_snippet.js`（也 gitignored），
**提交的源码里不含凭证真值**。

## 备选：patchright 人工接管（`tools/lv_prices_manual.mjs`）

开一个 patchright 隐身窗口让用户手动过 Akamai，脚本抓到有效会话后自动逐货号 fetch。
但本机若无 Chrome、且 patchright 窗口本身也可能被 Akamai 拒，**Safari 控制台法更可靠**，优先用它。

## 注意

- 取回的字段：`status`(200有价/410停售)、`priceRaw`、`sellable`、`name`、`color`、`nStore`(首尔线下可售数) 等。
- 精简版（`lv_snippet_gen.py` 生成的）不含逐 SKU 数组，只留货号级价 + 计数；要逐尺码库存用 `tools/lv_prices.mjs` 的全量字段或 `tools/sku_detail.py`。
- LV 是零售价、基本不变，缓存价长期可用；抓价主要为**扩更多候选**，不是每次必跑。
