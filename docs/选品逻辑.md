# 选品逻辑沉淀（倒爷思路）

把成熟代购/倒卖者的选品经验编码进 `scorer`，避免"差价大就上"的直觉陷阱。

## 核心：差价大 ≠ 赚钱

真正决定收益的是**单位时间资金回报率**，不是单件差价：

```
资金回报率 ≈ (单件净利润 / 单件采购成本) × 周转次数
```

一个差价 2000 但 3 个月卖一件的品，远不如差价 400 但一周卖五件的品。所以销量速度
（周转）与利润率必须一起看 —— 这就是评分里 `sales_speed` 和 `margin_rate` 都给高权重的原因。

## 七条经验规则（对应评分分项）

1. **高周转优先**：近30天有稳定成交的款 > 只有"想要"没成交的款。想要人数只能打折当弱信号。
2. **绝对利润托底**：利润率再高，单件净利 < 物流+鉴别的心理阈值（默认¥80）就不值得占人力。硬过滤掉。
3. **库存可得性是命门**：LV 端 `sellable=false` 的款，差价再大也是镜花水月。必须当前可买，最好持续可买（接历史后看连续可售天数）。
4. **避开易掉价款**：得物价格波动大的款（新品炒作、联名），到货时可能已腰斩。`price_volatility` 负向扣分。
5. **控制单件资金占用**：同样回报率，优先吃单价低的款，资金能铺更多 SKU、分散风险。`capital_tied` 负向。
6. **避开红海**：在售卖家/出价多的款，价格被卷到没肉。`seller_count` 负向。
7. **经典款 > 当季爆款**：老花/常驻款补货稳定、价格稳；季节/限定款断货快、风险高。可在货号清单 note 标注，后续做类目加权。

## 反直觉提醒
- "想要人数高"常是营销噱头，不等于成交。以成交量为准。
- 韩国免税/退税价低不代表稳赚 —— 得物到手要扣佣金+手续费，且鉴别不过会退货。算的是**到手净利**。
- 鞋类要看**尺码齐全度**：热门尺码（如 39-43）断货则实际可做的量大打折扣，单看货号可售会高估。

## 落地为可调参数
以上规则全部参数化在 `config/settings.yaml` 的 `weights` 与 `filters`。
跑一段时间后用**真实成交回测**校准权重：把实际卖出去、赚到钱的品的特征反推，调高对应权重。
